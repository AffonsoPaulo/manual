# Getting Started

This section takes you from a blank Laravel application to a live documentation site. The two steps are:

1. [Installation](./installation.md) — require the package, publish assets, scaffold your docs directory, and build the initial cache.
2. [Configuration](./configuration.md) — every configuration key explained, with guidance on when to change each one.

If you want to jump straight to writing content, run `php artisan manual:init` after installing and open `/manual` in your browser. The scaffold creates a ready-to-use structure you can start editing immediately.
